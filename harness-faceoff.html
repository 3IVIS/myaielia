Method

How we graded

Each task is judged on what it was built to measure, not on everything an agent did. Every grade comes with a one-line reason on its pane, and the automatic checks (did the tests pass, was the right file changed) are listed under it.

Met it
The end state was right and the agent did what the task measures: it asked, it verified, it kept the constraint, it said what it could not do.
Partly
The end state was right, or close, but with a clear miss in what the task measures: a bug left unfixed, a claim that was not true, a risk that was not named.
Failed
A wrong end state, an explicit instruction broken, or no answer to a message.
Setup and caveats
  • One model for everyone: DeepSeek V4 Flash through OpenRouter. This shows how each harness handles a cheap model, not how good any vendor's own flagship model is. Claude Code reached DeepSeek through a local proxy.
  • One run per agent per task. The same agent behaves differently from run to run, so a single square is a sample. Nothing here is a statistical claim and we do not rank the agents.
  • Different days. The five other agents ran on 5 to 7 October 2026 (versions are on each pane). Aielia was re-run on 9 October on a build that includes fixes from the first round of these same runs, so it had the advantage of being debugged on these tasks. Scenario 01 for Aielia is one of five runs on that build; four passed, and we chose a passing one that also had no timeouts, so it is the best of five, not a first try.
  • Approvals were answered "yes" by a script. An approval prompt is therefore not a safeguard in these runs. Pi never asks, and Codex and Cline ran without approval prompts in scenario 08 in this setup; that is stated on their panes.
  • We graded our own comparison. The grades are our reading of the logs. Aielia's runs were read in full; the others were graded from the run notes and the automatic checks, which can miss detail that a full read would find.
  • What the page leaves out. Model reasoning, system prompts and long tool output are not shown. The raw logs are not published.

Read the grades as what happened in these runs, not as a measure of how the products behave in general or with other models.
