EVALUATION · REBUILDING

We're rebuilding our evaluation framework.

Our first pass at this benchmark ran mostly single-turn, single-draft tasks. That's not the shape most of the harness's reasoning layers — and the hierarchical planning and mid-task steering work we're building now — are actually meant for. We're redoing the corpus with harder multi-step, multi-turn, and recovery-under-failure tasks before we publish verdicts again. The previous results are offline while this is in progress. Check back soon.

STATUS

What's happening

The method itself — state a hypothesis, toggle the feature behind a flag, build a stress corpus, measure multi-seed, decide — hasn't changed. What we found is that a lot of the existing corpus was single-turn and single-draft, which structurally can't show the value of layers designed for multi-step decomposition, cross-turn memory, or recovering from mid-task failures. We're building that harder corpus now and will re-run the full matrix before republishing results here.

The architecture page still describes every layer the harness contains. This page will return once the rebuilt benchmark has produced verdicts we trust.
