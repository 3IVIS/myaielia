GOOD TO KNOW

A few extras.

Why is there a security warning?

Apple and Microsoft want developers to buy a signing certificate, so the system can tell who published an app. We haven't yet, so macOS and Windows treat our downloads as coming from an unknown publisher. The warning is about identity, not a detected problem. Only bypass it for files from myaielia.com or github.com/3IVIS/buildaharness/releases. Linux shows no warning. We plan to sign the builds later.

How do I check my download is genuine?

Terminal releases come with a .sha256 file, and the same hashes are in aielia-latest.json. The installers check this for you. To check a manual download:

shasum -a 256 aielia-darwin-arm64        # macOS
sha256sum aielia-linux-x64               # Linux
Get-FileHash .\aielia-win32-x64.exe      # Windows (PowerShell)

The result must match the .sha256 file. Desktop installers don't have published checksums yet.

I downloaded the terminal program by hand. How do I run it?

Get the file for your system (Aielia {{ site.data.downloads.cli.version }}): macOS Apple silicon, macOS Intel, Linux x64 or Windows x64. Other files are on the release page. Then, on macOS and Linux, make it runnable; on macOS also clear the download mark; on Windows, unblock it:

chmod +x aielia-darwin-arm64
xattr -d com.apple.quarantine aielia-darwin-arm64   # macOS only
./aielia-darwin-arm64 --version

Unblock-File .\aielia-win32-x64.exe                  # Windows
Where is my data, and how do I uninstall?

Uninstalling never deletes your chats. Delete these folders yourself if you want them gone.

Terminal: ~/.buildaharness/personal-assistant/. Uninstall by deleting the aielia program (Windows: the %LOCALAPPDATA%\Aielia folder and its PATH entry).

Desktop: macOS ~/Library/Application Support/com.buildaharness.assistant/; Linux ~/.local/share/com.buildaharness.assistant/; Windows %LOCALAPPDATA%\com.buildaharness.assistant\. The desktop app doesn't update itself yet: install a newer release over the old one.

Can I build it myself instead?

Yes, and a build you compile yourself carries no warning. You need Node.js (we use 22) and, for the desktop app, Rust 1.88 or newer.

git clone https://github.com/3IVIS/buildaharness
cd buildaharness
npm ci
npm run build:harness && npm run build:runtime && npm run build:aielia
npm run dev:desktop
The installer won't overwrite my existing aielia

Something else (often an npm-linked aielia) is already there. Remove it, or re-run with force: curl -fsSL https://myaielia.com/install.sh | sh -s -- --force, or on Windows set $env:AIELIA_FORCE = '1' first.

Still stuck? Open an issue on GitHub with your system, which download you used and the exact message.
