WHAT IT DOES

The model suggests. The harness decides.

  1. Right-sized checks

    The checks scale to the task.

    A plain fact question is answered straight away. A real task runs through all eleven layers of the harness, from understanding the request to a final review. The eleven layers →

  2. Planning

    Big requests become small, checked steps.

    Ask for several things and it splits them into a short plan, with the safety rules applied to every step. Want to see the plan first? Plan mode (off by default) drafts one and runs nothing until you approve it. How a message is handled →

  3. Customizable

    You choose which layers run.

    You get to choose which layers should run. Switch any reasoning layer on or off, with /layers in the terminal or in Settings in the desktop app. The core layers always stay on. See the layers →

  4. Adaptive mode · experimental

    The harness can pick its own layers for each turn.

    The harness can decide which layers to run, to get the best balance of cost and benefit. It is off by default for now, as we keep fine-tuning it. How we test it →

  5. Goals and next steps

    Every goal keeps its own thread.

    Aielia tracks each goal separately across the conversation. After a reply it can suggest up to three next steps. How goals are tracked →

  6. Steering

    Change your mind mid-task.

    Send a message while it is still working and it absorbs it into the job in progress.

  7. When it gets stuck

    A supervisor steps in when it stalls.

    If a job stops making progress, one bounded call picks a way out: change direction, look at it differently, gather more facts, or stop. See the supervisor →

  8. Lists of work

    It works through lists one item at a time.

    Each item gets its own search and its own limit, so one dead end can't use up the effort for the rest. The reply says which items it found, which it couldn't, and which it ran out of effort on.

  9. Whether it's right

    Answers are reviewed before you see them.

    Replies get a review and a partial fact-check (2 of 9 checks run in chat today). Answers that used tools show their evidence and a label: verified, unverified, contradicted, or no evidence.

  10. What can't be undone

    Changing files, running commands and sending email wait for your OK.

    They're shown to you first and only happen after you approve (unless you opt out).
