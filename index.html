THE ASSISTANT · AIELIA

Talk to it. It stops before it acts.

Aielia is a general-purpose chat assistant that walks a full 11-layer harness on every real turn. A quick fact lookup stays light. Anything consequential — sending an email, paying, running a shell command, deleting a file — pauses for your approval before a single token is spent.

the risk gate, in practice
> What time zone is Tokyo in?
Japan Standard Time (UTC+9).

> Send an email to my boss saying I quit.
⚠ needs approval — this looks consequential (send).
  Reply "approve" to proceed. No model call was made.

Why it's different

Per-tool-call control state

Every read-only tool call is checked against a live 5-tier resolver before it runs — deterministic ALLOW / DENY / REQUIRE_APPROVAL, not an advisory hint.

Fail-safe risk classification

A classifier error resolves to "requires approval" — it never defaults to low-risk. Judged in any language, not just English.

Staged effects

write_file, run_shell_command, and send_email stage the exact action for approval — no second model call can improvise a different one.

Untrusted-content boundary

Web results and shell output are wrapped as data the model is told never to obey, and survive a crash mid-turn via checkpoint resume.

WHY YOU CAN TRUST IT

Helpful by default, careful by design.

The assistant proposes; the harness decides what happens next. That split is what lets Aielia be quick about the easy things and firm about the ones that can't be undone.

Asks before it acts

Sending, paying, deleting, or running a command pauses for your approval. The exact action is staged first, so nothing can be swapped in after you say yes.

Your keys, your machine

No Aielia account. Bring your own model key — it stays in your browser or a local config file — or reuse a Claude CLI login and skip the key entirely.

Doesn't obey the web

Web pages and command output are wrapped as untrusted data the model is told never to follow, so a page that says "ignore your instructions" is just text.

Picks up where it left off

The harness checkpoints mid-turn. If something crashes halfway through a conversation, the interrupted turn resumes instead of starting over.

FAQ

Questions, answered.

What is Aielia?

An open-source chat assistant that answers a quick question in one step and stops for your approval before it does anything consequential — sending an email, paying, deleting a file, or running a command. Every real turn runs through an 11-layer harness that checks the reply before it reaches you.

What does it ask my approval for?

Anything that looks consequential — send, delete, pay, post — is caught before a model call is made, in any language. Writing a file, running a shell command, and sending an email always stage the exact action and wait for your explicit approval. If the safety check itself fails, it asks rather than assuming the request is harmless.

Do I need an account?

There is no Aielia account or sign-up. You bring your own model key — Anthropic, OpenAI, or OpenRouter — or reuse an existing Claude CLI login in the terminal. In the browser build the key stays in your browser; in the CLI and desktop app it sits in a local config file.

Where does it run?

In a browser tab (nothing to install), in a terminal via npx @buildaharness/aielia, or as a native desktop app. All three share the same assistant and the same harness — they differ only in where your data is stored.

Is it open source, and who makes it?

Yes — Apache 2.0. Aielia is made by 3IVIS and built on Build A Harness, the open-source framework for designing and running agent harnesses. It is an early-stage project (v0.3.1), not an audited security product.
