Set up Brave Search

This lets Aielia search the web to find sources for your claims. Seven steps, about five minutes, with a spending limit so there are no surprise bills.

  1. Create your account

    Go to api-dashboard.search.brave.com and sign up or sign in.

  2. Choose the Search plan

    In the left menu open Available plans. On the Search plan ($5.00 per 1,000 requests) click Get started. It includes $5 of free credit every month.

    Brave asks for a card to stop abuse. At signup you can set your prepay amount to $0.

  3. Create an API key

    Open API keys in the left menu and click + Add API key. Name it, then use the copy icon to copy the key and keep it private.

  4. Set a monthly usage limit

    Open Usage limits and click Edit on the Search row. Tick Override monthly usage limit. Under New monthly spend choose Free, or $10.00, $25.00, $100.00 or Custom, then save.

    Free says "$5.00/mo in free credits — you won’t be charged". If your plan already shows Free credits only, you are set.

  5. Keep auto-reload off, or capped

    Open Credits balance. Auto-reload is optional. If you turn it on, also set its monthly cap.

    Without a cap, auto-reload keeps topping up every time your balance falls below the trigger. If your balance runs out with it off, Brave simply pauses the service.

  6. Turn on a usage alert

    Open Usage alerts and set an email warning, so you hear about it before anything stops.

  7. Paste the key into Aielia

    In Aielia Write open Settings, then Web pages and sources, and paste the key into Search key. Leave Page proxy as it is. In the chat app the field is called Brave API key.

    Then in the chat pane choose Search the web for sources and verify the claims.

    Aielia keeps the key in your browser and sends it with each search. It is not stored on the proxy.

Checked in the Brave Search API dashboard in November 2026. Prices, free credit and button names can change, so confirm them on Brave’s plans page.
